# DRIVEO

**DRIVEO – Digital Car Showroom**

DRIVEO merupakan website e-katalog showroom mobil yang dirancang untuk memudahkan pengguna dalam mencari, melihat, dan memperoleh informasi mengenai berbagai pilihan kendaraan secara online.

Website ini dilengkapi dengan fitur pengelolaan kendaraan serta AI Analitik dan Rekomendasi Mobil untuk membantu pengguna memperoleh informasi dan menemukan kendaraan sesuai kebutuhan.

## Fitur Utama

- Katalog dan pencarian kendaraan.
- Informasi detail dan spesifikasi mobil.
- Login dan registrasi pengguna.
- Dashboard admin untuk mengelola data kendaraan.
- **AI Analitik** untuk menganalisis data dan informasi kendaraan.
- **Rekomendasi Mobil** berdasarkan kebutuhan dan preferensi pengguna.
- Fitur konsultasi seputar kendaraan.
- Responsive design untuk berbagai perangkat.

## Teknologi yang Digunakan

- **Frontend:** Vue.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **AI Integration:** Google Gemini API

## Instalasi dan Menjalankan Project

Clone repository:

```bash
git clone [LINK-REPOSITORY]
```

Masuk ke direktori project dan instal dependencies:

```bash
npm install
```

Jalankan aplikasi:

```bash
npm run dev
```

Pastikan konfigurasi database dan environment variables sudah disesuaikan sebelum menjalankan aplikasi.
